## 打包

赛事方要求提交一个 Zip，包内根目录为 `团队名称_初赛提交材料/`。用下面的脚本生成，不要手动压：

```bash
bash build_submission.sh
```

产物为 `香蕉皮2026_初赛提交材料.zip`，位于本目录上一级。

如果本次不参加真机创新可选任务，先把 `05_真机创新可选任务/` 删掉或清空，脚本允许该目录缺失。

## 注意

`03_模型权重/` 默认被 `.gitignore` 忽略，权重只进 Zip 不进 Git。如果确实要纳入版本管理，用 `git add -f`。

`01_评测结果/results.json` 的字段结构参照赛事方【必读_模板和目录要求】整理，正式提交前请以赛事方在天池页面「数据」区放出的官方模板为准，字段名如有出入以官方模板覆盖。
